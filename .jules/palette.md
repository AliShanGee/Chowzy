## 2025-05-14 - Delightful Empty States and Theme-Aware Accessibility
**Learning:** Replacing a static "Empty" message with an animated state using Lottie significantly increases user engagement and provides a more polished feel. Additionally, hardcoded color classes (like `text-white`) can break accessibility in light mode; theme-aware conditionals are essential for maintaining readability across different user preferences.
**Action:** Always check for existing animations that can be repurposed for empty states and use theme-aware Bootstrap classes or CSS variables for text colors.
