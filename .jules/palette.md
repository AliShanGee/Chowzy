## 2025-05-22 - [Empty Cart UX Enhancement]
**Learning:** A static "Empty Cart" message acts as a dead-end for users. Providing a clear call-to-action (CTA) button to "Explore Menu" alongside a visually pleasant empty state (using glassmorphism and animations) significantly improves user retention and navigation flow.
**Action:** Always include a helpful CTA in empty states to guide users back into the core application loop.
