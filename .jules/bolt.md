## 2026-07-19 - Home.js Render-Loop Optimization
**Learning:** Evaluated nested loops and filters within React components' rendering paths ($O(C \times N^2)$ where $C$ is unique categories and $N$ is food items) can severely slow down search responsiveness on every keystroke. Pre-grouping data in a single-pass $O(N)$ pass using standard JS `Map` and `Set` collections wrapped in `useMemo` avoids redundant iteration and renders components instantly.
**Action:** When handling datasets that require filtering, category-grouping, and item deduplication, hoist the parsing logic to the top level under `useMemo` hooks, leveraging a category-keyed Map to achieve O(1) query lookup during child component mapping. Ensure to check `foodItem.length > 0` globally instead of checking category map item lengths inside the mapped blocks to avoid displaying false-positive "No Such Data Found" text for categories that simply do not have current matches for the typed search string.
