## 2025-07-26 - Decoupling Legacy Modules via Route-Level Code Splitting
**Learning:** Monolithic route imports of legacy sub-modules (such as the React-Admin dashboard inside `AdminPanel.js`) act as both a massive performance bottleneck and a compile-time liability. Synchronously importing `react-admin` and its material-UI peer dependencies (`@mui/material`, `@emotion/react`) forced every user to download and compile an extra 387 kB (gzipped) of JavaScript. Furthermore, build systems like `react-scripts` would fail the entire build if any dependency in the unused admin branch was missing.
**Action:** Always lazy-load heavy, isolated branches (like Admin Panels, custom video players, or charts) using `React.lazy()` and `React.Suspense`. This isolates heavy third-party dependency trees, prevents them from blocking the initial render, and protects the main bundle from compilation failures originating in secondary modules.
