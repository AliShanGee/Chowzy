## 2025-07-18 - Non-semantic Toggles and ThemeToggle Accessibility
**Learning:** In highly interactive React applications with multi-theme support, components like theme toggles are frequently built using generic divs or custom containers to ease styling and animations (e.g. Lottie). This practice makes them completely invisible to screen readers and inaccessible to keyboard users unless explicitly built with semantic elements or full ARIA role and keyboard bindings. Converting interactive divs to semantic `<button>` elements with clear `aria-label` and `aria-pressed` attributes combined with custom reset CSS styles allows seamless alignment with the visual design while complying fully with modern a11y standards.
**Action:** When creating or refactoring interactive custom toggle elements, always prefer semantic `<button>` elements over generic divs, reset default button styles, and provide descriptive ARIA tags to announce their current state and action clearly.
