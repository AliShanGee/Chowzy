## 2025-05-18 - React.memo and O(N) Filtering Optimizations in Home and Card Components
**Learning:** In React components rendering large dynamic list collections (like food item cards and categories in `Home.js`), inline $O(N^2)$ deduplication checks (`filter` + `findIndex`, or `filter` + `reduce` with `.some()`) re-run on every render frame and re-allocate objects/arrays, causing noticeable frame drops during user typing. Using `useMemo` with a native `Set` for deduplication reduces complexity to $O(N)$ and eliminates unnecessary re-renders. Wrapping leaf components (`Card`) in `React.memo` and hoisting static configs prevents unnecessary Framer Motion spring calculations when parent search/pagination state updates.
**Action:** Always prefer `useMemo` + `Set` for deduplicating or filtering collections in React render methods, hoist static animation config objects to module scope, and wrap frequently rendered list items in `React.memo`.
