## 2025-03-02 - Form and Input Accessibility Issues
**Learning:** Icon-only password visibility toggles, address buttons, and search inputs are highly inaccessible without clear `aria-label` tags and `aria-pressed` state tracking. Additionally, React Bootstrap standard form controls require explicit `controlId` association on `Form.Group` wrapper elements to dynamically link `<Form.Label>` and `<Form.Control>` tags together, ensuring screen readers can correctly associate the input value descriptions.
**Action:** When creating form inputs, ensure each `<Form.Group>` has a unique `controlId` attribute, and ensure any custom or third-party input wrapper (such as `<PhoneInput>`) explicitly maps an `id` to the label's `htmlFor` attribute. Any icon-only toggle or action button must always include a descriptive, localizable `aria-label` and correct dynamic attributes like `aria-pressed`.
