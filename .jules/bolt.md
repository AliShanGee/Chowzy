## 2025-05-14 - Home.js Render Loop Optimization
**Learning:** The previous implementation of Home.js had nested O(C * N^2) logic (where C is the number of categories and N is the number of food items) inside the render loop. This was caused by filtering and then reducing (deduplicating by name) food items for every single category during every render, including on every keystroke in the search bar. Synthetic benchmarks showed that replacing this with a single O(N) pre-processing step using useMemo and a Map reduced render-time complexity significantly (~7.5x improvement for 5000 items).
**Action:** Always check for nested array operations (filter/reduce/find) inside .map() calls in React components, especially when they depend on high-frequency state like search inputs. Memoize these calculations at the top level of the component.
