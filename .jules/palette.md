## 2025-05-15 - Interactive & Accessibility Polish
**Learning:** Using semantic `<button>` elements instead of `div` or `span` for interactive Lottie animations and icons significantly improves accessibility (keyboard/screen readers) without sacrificing design.
**Action:** Always wrap interactive Lottie/SVG components in a semantic `<button type="button">` with a descriptive `aria-label`.

**Learning:** Empty states are a prime opportunity for "delight" and user guidance.
**Action:** Use existing Lottie assets and clear "Call to Action" buttons to transform empty screens into helpful navigation points.
