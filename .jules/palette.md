## 2025-02-27 - Custom Interactive Div Keyboard Navigation & Interactive Empty States
**Learning:** In highly interactive React applications with custom styling, custom visual components like circular fixed arrow divs are often used instead of default semantic button elements to fit layout requirements. When using a `motion.div` as a button, it is essential to support accessibility by adding `role="button"`, `tabIndex={0}`, an explicit `aria-label`, and handling both `Enter` and `Space` key presses. Additionally, an empty state page must never be a dead end for users. Supplying a prominent call-to-action button (like "Browse Foods" or "Browse Menu") that links back to a hub page increases session depth and improves overall retention.
**Action:** Always verify that custom icon toggles and circular controls are navigable by keyboard (role, tabIndex, onKeyDown) and ensure empty list states offer an interactive path forward rather than a static text message.
