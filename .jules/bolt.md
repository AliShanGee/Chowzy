## 2025-03-04 - Linear O(N) Memoized Grouping and Component Memorization
**Learning:** Performing nested iteration, filtering, and O(M^2) copying deduplication (e.g. array.reduce + array.some) inside rendering blocks results in an O(C * N^2) bottleneck. When triggered on every keystroke of a search input, it degrades responsiveness significantly. Shifting categories deduplication to O(C) using Set, and food items filtering/deduplication to a single-pass O(N) pass utilizing native Maps and Sets inside a useMemo hook, drastically speeds up execution. Combining this with wrapping children components in React.memo prevents redundant re-renders of stable elements when unrelated theme/page states change.
**Action:** When mapping categories or long lists with nested filtering and search terms, avoid computing combinations in rendering logic. Instead, group, filter, and deduplicate collections inside a single-pass O(N) Map/Set within a useMemo hook, and ensure that list components use React.memo to preserve rendering efficiency.
